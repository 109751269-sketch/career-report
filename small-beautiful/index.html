一、结论速览

结论 1：你的怀疑成立，岗位不是没有，是没被推给你。BOSS 直聘官方算法备案写明：推荐算法「基于求职意向、交互行为……通过多种召回模型和深度神经网络排序模型」推荐职位，且「会根据用户交互行为对推荐模型进行反馈，不断优化推荐结果」——越点什么越推什么，形成闭环。而本次扫到的稳定型雇主（银行、农商行、国企数科、专精特新、外企研发中心、垂直 SaaS）主要沉在猎聘、智联、地方人才网、企业官网、中国中小企业服务网、高校就业网里，很少出现在推荐流首屏。
结论 2：对口岗位充足，且「小而美 + 双休」与「高薪」的交集确实存在，但只在特定类型公司出现。本次共汇总 — 条岗位线索、— 家公司尽调。交集集中在三类：已盈利/上市/国资背景、国家级专精特新小巨人、工程师文化的小团队。纯投放优化师岗（6–15K、大专可）与 10 年经验严重错配，已单独标注，不建议投。
结论 3：第一梯队按「对口度 × 稳定性 × WLB 可信度」排序如下（详见第四节完整表）：
① 瑞幸咖啡「广告投放算法专家 30-60k·14薪」——JD 与你的 RTA / CTR-CVR / 预算分配 / 人群扩展 / ROI-LTV 几乎 1:1，品牌方自建团队、扁平+弹性；② Novabeyond「程序化广告算法工程师」——双休、加班有加班费、算法岗可居家办公写入福利条款；③ 翊坤万维「算法工程师(营销策略推荐) 20-40K」——JD 明写金融意向响应模型与风控模型优先、LR/GBDT/XGBoost/pyspark；④ 瑞狮网络（12 年老牌 AdTech）「广告算法专家 30-80K」；⑤ 杭银消金「策略分析师-信贷 3.5-4.5 万/月」——本清单金融方向薪资最高。稳定/WLB 优先则看：华润置地、贝壳找房、太保财险、国能日新、进门财经、世强先进。小赢科技因 2026 年业务急剧收缩，已从 A+ 降至 C、移出第一梯队（见 6.6）。
结论 4：有几家「看起来很美」的必须避开或先核实。尽调发现：今日水印相机（2 亿美金 C 轮/过亿利润全为自述、岗位标大小周、签约主体一串公司）、Moboost（三套工商主体、人数同比下滑）、太字流动 / 广推科技 / Bidnex / Avia（25–34 人小微却开 50–200K，高薪异常）、信用生活（股权冻结/税务催缴/子公司限高）、梅州客商银行（广深岗实为长期出差）。详见第五节公司尽调表 D 级。
结论 5（2026-11-13 口碑复核后新增）：6 家已从推荐名单剔除。用 web-analysis-ai 技能重抓脉脉最新评价 + 牛客公开 API + 第三方职Q/看准交叉验证后：大宇无限（多源指向长期加班、人员流动大）、深圳联友科技（加班、压抑，4/4 负面）、安踏集团（996、加班无加班费）、赢商股份（福利几乎没有、无年终奖、涨薪难、勾心斗角）、国轩高科（社保/公积金最低基数、无偿加班、关系户）、万辰集团（证监会立案）已剔除；另有 8 家降级。证据与原文见第八节。
结论 6（2026-11-13 晚 · 四维重评后新增）：第一梯队由 11 个缩到 8 个，且不只小赢一家有问题。补做业务/财务/行业/雇主动态四维尽调后发现：翊坤万维已于 2025-09-23 注销、参保 1 人（此前被排在第 3）；广州智谱网络参保 4 人却宣称 600 人、主体 2023 年成立却宣称 2012 年；贝壳一年净减 24,472 人、研发 -17.4%；杭银消金净利连续 -21%、信用减值占营收 74.9%；瑞幸自营同店 -11.1%。太保、沃尔玛、Novabeyond、华润置地因基本面稳健进入/留在第一梯队。核心教训：口碑是滞后指标，业务是先行指标；评级必须四维交叉，不能只凭员工评价。

二、为什么会「刷不到」：机制与破圈操作

🔍 机制（官方口径，硬证据）

  • BOSS直聘《算法及模型备案公示说明》：求职招聘推荐算法（网信算备110105475271702230015号）「根据用户的求职招聘意向、交互行为……通过多种召回模型和基于深度神经网络的排序模型」推荐职位，并「根据交互行为对推荐模型进行反馈，不断优化推荐结果」。
  • 搜索算法（网信算备110105475271704240011号）同样「根据搜索词和交互行为」调整结果，虽引入多样化技术，仍受你历史行为影响。
  • 隐私政策明确：可关闭「个性化职位推荐」，关闭后仅按你自主设定的条件（求职期望、目标地点、简历）展示内容，不再基于行为推送。
  • 推论：你的简历标签是「消费金融 + 广告获客 + 数据挖掘」，历史点击又集中在这类岗位，模型就会持续召回同类；银行、国企、制造业、垂直 SaaS 的岗位即便存在，也很难进入首屏。

🛠 五个可立即执行的操作

  • 关掉个性化推荐：设置 → 隐私保护 → 个性化职位推荐（官方隐私政策确认有效）；同时清理搜索历史。
  • 手机 App / PC 网页端交替刷：两端岗位库与推荐逻辑不完全同步，PC 端更容易出现未买曝光的自然流量岗位（经验帖，非官方保证）。
  • 手动改定位到目标城市的产业园 / 写字楼密集区，很多中小公司只定向推给周边求职者。
  • 按「最新」排序，而不是「推荐」；双休高薪岗窗口期常只有几小时。
  • 搜资质词而非行业词：瞪羚企业、专精特新、小巨人、国企、六险一金、周末双休、不加班、弹性工作。

6.5 证据分级与局限

  • A 级（可核）：技能抓取的脉脉 / 牛客原始帖，带日期、公司字段、原文，可按 data.json 复核。
  • B 级（可参考）：职Q / 看准 / Glassdoor 匿名评价、招聘公众号福利条款；存在单条、样本小、主体不可确认的问题，已在表中标注。
  • C 级（不足以判定）：只有公司自述（招聘页「不内卷/无加班」）、或完全无评价；本报告不把 C 级当好评。
  • 评价主体错位：杭银消金、太保、沃尔玛的负面评价多来自销售/门店/基层岗，与总部数据策略岗的工作形态不同；不能直接等同，也不能反过来证明总部好——只能面试按团队核实。
  • 内推软文污染：牛客贝壳 131 条中大量为「内推码/校招/投递」帖，清洗后仅剩 2 条真实体验；因此牛客只作旁证。
  • 时效：部分评价为 2022-2024 年，组织与团队可能已变化；脉脉最新两天无目标公司新帖，无法验证「当下」口碑。

八、结论与问题

结论

  • 方向③ 是对口度最高、薪资最高的主攻方向：品牌方自建投放算法团队（瑞幸）、持牌消金/Fintech 获客策略（小赢、Akulaku、杭银消金）、出海 AdTech/DSP（瑞狮、Novabeyond、大宇无限、翊坤万维）三类都能直接复用 RTA / CTR-CVR / 多目标获客 / 媒体联合建模 / 回传优化经验；非大厂算法岗主流 20-50K、14-16 薪，明确写双休/不加班的算法岗约 30-45K。
  • 方向①② 是「稳定 + WLB」机会最密集的方向：持牌金融、城商/农商行、国企央企数科、能源制造、外企，主流 10-30K，但普遍用 13/14/16/20 薪补偿现金天花板（顺德农商 20 薪、广发证券 16 薪、平安健康险 16 薪、建信金科 14 薪）。
  • 方向④ 是差异化加分项，不是主攻方向：带 WLB 标签的 AI 应用岗多在 7-18K，20-35K 以上多为 Agent/FDE 资深岗且不写双休；真正的高薪+WLB 交集只在已盈利/上市/国资/专精特新与工程师文化小团队。FDE（前向部署工程师）是 2026 年风口，恰好吃「10 年业务经验 + PMP + 把模糊需求翻译成可量化降本增效」的能力，值得作为④的主攻细分。
  • 高薪与 WLB 在中小公司里近似互斥：二线城市（西安/成都/重庆/苏州/嘉兴/合肥）「双休」标题密度显著更高——要 WLB 就往非一线 + 小团队找；西安还形成了程序化广告小公司集群（Moboost / 超斯塔 / HeheMobi / Novabeyond / 新义互联），这批岗在 BOSS 常规推荐流里几乎不出现。

问题与待确认

  • 城市未确认（最重要）：简历未写现居地/期望城市，本报告按全国覆盖，含北京、上海、深圳、广州、杭州、成都、西安、重庆、苏州、南京、合肥、厦门、武汉、长沙、天津、嘉兴、郑州、南昌等 20+ 城市。请确认 1-2 个优先城市，可把岗位池迅速收敛到 20-30 条。
  • 薪资底线未确认：10 年经验合理带约 25-40K；但稳定型雇主（国企/银行/制造）普遍 15-25K + 多薪，若把「稳定/WLB」权重调高，需要接受约 20-30% 的现金折让。请明确是「薪资优先」还是「WLB 优先」。
  • 是否接受出差 / 驻场 / 派遣：梅州客商银行广深岗实为长期出差、零一万物 FDE 需 50% 出差、信用生活需异地驻点、外企德科派驻大疆与深圳市银雁为派遣/外包，均与「兼顾生活」冲突；请确认红线。
  • 年龄门槛：顺德农商、梅州客商、部分城商行与国企岗写「35 周岁以下 / 30 岁以下」，需先自查再投，避免无效投递。
  • 数据时效与来源局限：本报告岗位来自 2026-11-12 当天搜索引擎收录的招聘卡片摘要，BOSS 直聘详情页被登录墙拦截，未能逐条打开原 JD 验证；部分记录标注「90 天前更新 / 职位已关闭 / 已结束 / 该职位信息待核验」，投递前必须点开原链接复核公司主体、薪资、作息与是否仍在招。
  • 福利标签不可全信：地方人才网几乎每条都挂「全勤奖 节日福利 不加班 周末双休」，是网站模板字段；qfskill.com 的 scan-xxx 页面为 AI 生成的 SEO 岗位趋势文；大量「不卷不加班 / 已全面盈利 / C 轮 2 亿美金」是雇主单方自述，无第三方佐证，已在表中逐条标注。
  • 薪资口径不统一：有「30-60k·14薪」「3.5-4.5万/月」「20000-30000元」「1.2-1.5万·13薪」「面议 / 薪资未公开」多种写法，本报告一律照抄原文未做换算；「·X薪」为该平台标注的年度发放月数，不与月薪直接可比。
  • 用工主体风险：多条「国企/央企/外企」实为派遣或外包；今日水印相机、Moboost、Bidnex、Castbox 等存在多主体或主体混淆，面试须书面确认签约主体全称、社保公积金基数、期权归属、近 12 个月人员变动。
