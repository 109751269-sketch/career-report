# 求职研究站 · career-report

三个基于公开职场数据的求职 / 能力专题，浅色静态页，GitHub Pages 托管。

在线地址：<https://109751269-sketch.github.io/career-report/>

## 专题

### 1. 求职 · 小而美（`/small-beautiful/`）
- 217 条去重岗位线索，覆盖数据分析/模型开发、分析与策略、广告投放算法/模型、AI 应用落地四个方向
- 36 家公司尽调、24 条员工口碑记录，**2026-11-13 晚完成四维（业务/财务/行业/雇主动态）重评**
- 默认隐藏 8 家口碑或主体有问题的企业，可取消勾选查看
- 每条岗位均可点击跳转原始 JD；第一梯队 8 个组合附 JD 链接
- 四维重评结果：**翊坤万维（已于 2025-09 注销）、广州智谱（参保 4 人 vs 宣称 600 人）剔除**；贝壳、杭银消金降为 C+；太保、沃尔玛、Novabeyond、华润置地升/稳为 A-~B+；小赢科技维持 C
- 评分口径：基本面 40% + 口碑 25% + 岗位匹配 25% + WLB 10%，附一票否决规则

### 2. 求职 · 互联网大厂（`/bigtech/`）
- 41 家公司综合总榜：时薪 30% + 工时 20% + 强度 15% + 满意度 20% + 成长 15%
- 9 维口碑剖面（加班/薪资/福利/压力/组织管理/WLB/技术成长/稳定性/面试门槛）
- 双源分歧表（脉脉 vs 牛客）、年薪 × 工时性价比象限
- 可排序、可搜索，纯静态无外部依赖

### 3. 技能盘点 · web-analysis-ai（`/skill-audit/`）
- 新增于 2026-11-14。渠道矩阵（脉脉 / 牛客 / 职友集 / 小红书 / X）：取数方式、登录态、风控特征、当前状态、数据量
- 脉脉专题清单：4 个固定专题 + 频道 / 搜索补抓，帖子量（原始 / 去重）、评论量（明确区分「未抓」与「旧格式不可用」）、覆盖时间、最近抓取
- **评论能力评估**：确认四大专题评论量为 0 是「没抓」而非「无评论」；RSC 里的 `cmts` 是真实评论数、`title` 是评价对象公司名；详情页可拿到结构化评论并与帖级关联
- 实测：20 帖小样本覆盖率 96.1%；**全量一轮 139 帖 / 声明 4,171 条 / 抓到 3,673（88.1%）/ 清洗后有效 3,045（82.9%）**；清洗规则（站内标签 / 乱码 / 广告 / 求职搭话 / 无效 / 重复）与误杀复核
- 按公司评论证据清单：贝壳找房 58 条（样本足）、沃尔玛 10 条（样本足）、联友 5 条（偏薄）、明略/瑞幸各 2 条（不足）；对齐「<10 条不得给 A」规则
- 数据健康度：相对时间解析产生 1,212 条未来日期、旧评论 5,938 条结构不可用、牛客内推软文、小红书详情覆盖率 5.5%、职友集 IP 风控
- TODO 看板：已完成 5 项 / 进行中 3 项 / 待办 5 项
- 公开页不含 Cookie、账号与具体风控阈值

## 数据来源
脉脉（四大专题去重 42,558 帖）、牛客（7,092 条记录）、职友集（34 个公司 ID / 29 条岗位细分薪资）、小红书（2,162 条列表 / 168 篇详情 / 1,034 条评论）、BOSS直聘/猎聘/智联等公开招聘 JD。

## 口径提醒
- 三个渠道口径不同：脉脉偏在职吐槽、牛客偏校招印象、职友集偏招聘事实，不能直接等同。
- 排名权重是主观的，换权重会改排名；样本量小、时间窗口不一的公司波动更大。
- 公司级数据会掩盖部门差异；投递前请以企业最新官方 JD 与劳动合同为准。
